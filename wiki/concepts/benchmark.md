# Benchmark

A benchmark is a standardized evaluation framework that allows consistent measurement of AI capabilities across different systems. Key properties:

- **Ground truth** — definitive correct answers or reference behaviors
- **Metric** — quantitative measure of performance
- **Baseline** — reference performance to compare against
- **Coverage** — how well the benchmark covers the capability space

Well-known AI benchmarks:
- **MMLU** — massive multitask language understanding
- **GSM8K** — grade school math
- **HumanEval** — Python coding from OpenAI
- **SWE-bench** — real-world software engineering issues
