# Category Theory

Category theory studies abstract structures and the relationships between them. It provides a unifying language for mathematics, focusing on:

- **Objects** — the entities being studied
- **Morphisms** — structure-preserving maps between objects
- **Functors** — mappings between categories
- **Natural transformations** — mappings between functors
