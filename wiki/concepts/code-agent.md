# Code Agent

A code agent is an AI agent specialized in software development tasks including:

- **Code generation** — writing code from specifications
- **Debugging** — identifying and fixing bugs
- **Refactoring** — improving code structure without changing behavior
- **Testing** — generating and running test suites
- **Code review** — analyzing code for issues

Code agents typically have access to:
- File system operations
- Shell/terminal execution
- Git operations
- Documentation lookup
- Test runners and debuggers
