# Control LLM

*Stub — needs real content*

Control LLM is a mitigation approach for catastrophic forgetting in LLMs that splits model layers into frozen branches (preserving prior knowledge) and trainable branches (acquiring new knowledge). Referenced in the ML Evolution Benchmarking Protocol article.
