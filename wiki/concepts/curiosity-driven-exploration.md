# Curiosity-Driven Exploration

## Definition

Curiosity-driven exploration is a paradigm in reinforcement learning where an agent's exploration behavior is shaped by *intrinsic motivation* — signals generated by the agent's interaction with the environment rather than external task rewards. The core idea: the agent learns a model of which environmental states or transitions are novel or surprising, and uses this intrinsic signal as a supplementary reward to drive deliberate exploration of undercovered regions of the state-action space.

In contrast to naïve exploration strategies (random action, ε-greedy), curiosity-driven methods actively seek out states that improve the agent's model of its environment — treating exploration as a skill with its own value function, not just a perturbation around exploitation.

## Core Mechanisms

### 1. Novelty Detection

The agent maintains a model that estimates how "familiar" each state is. Novelty can be measured by:

- **Count-based**: How often has this state (or similar state) been visited? (Table-based: UCB, hash-based: CTRWs)
- **Prediction error**: How well does the world model predict the outcome of actions in this region? High prediction error = high novelty = intrinsic reward
- **Ensemble disagreement**: Multiple models trained on the same data disagree more on unfamiliar states; disagreement = intrinsic reward
- **State visitation density**: States in low-density regions of the visited distribution get higher intrinsic reward (related to maximum-occupancy)

### 2. Surprise-Based Intrinsic Motivation

Surprise measures the gap between expectation and observation:

```
intrinsic_reward = f(prediction_error) = f(|predicted_outcome - actual_outcome|)
```

Key distinction from novelty: surprise is about *transitions* (action taken → outcome observed), novelty is about *states* (static property of the state space). Surprise-based methods reward the agent for getting things "wrong" — which drives it toward regions where its model is inaccurate.

The canonical formulation from Oudeyer & Kaplan (2007): intrinsic motivation drives exploration toward regions of maximum learning progress (improvement in predictive model), not just maximum prediction error. This avoids the "noisy TV" problem — pure prediction error can get stuck on random noise, but learning progress (rate of model improvement) naturally navigates toward structured complexity.

### 3. Information Gain

Information-gain approaches reward the agent for actions that reduce uncertainty about the environment:

```
intrinsic_reward = I(environment_state ; action) = H(p(s')) - H(p(s'|action))
```

Or in terms of world model improvement:

```
intrinsic_reward = KL(p(model after observing) || p(model before observing))
```

Information gain is theoretically principled but computationally expensive — it requires maintaining uncertainty over model parameters or simulating counterfactuals.

## Relationship to Maximum-Occupancy Principle

Maximum-occupancy principle (MOP) and curiosity-driven exploration share a common goal — covering the state space efficiently — but take different approaches:

| Dimension | Curiosity-Driven | Maximum-Occupancy |
|-----------|----------------|-------------------|
| Signal | Intrinsic (prediction error, surprise) | Extrinsic (state density in embedding space) |
| Objective | Maximize learning progress | Maximize state visitation evenness |
| Failure mode | Noisy-TV problem (random noise maximizes surprise) | Mode collapse to low-density but useless regions |
| Typical use | Dense intrinsic reward, works with sparse external reward | Skill discovery, behavioral diversity |

The two approaches can be combined: MOP provides a coverage objective, curiosity provides the directional signal toward high-learning-progress regions. This is the insight behind methods like [[maximum-occupancy-principle]] that use embedding-space density as the coverage metric while allowing curiosity-style intrinsic rewards to guide the exploration policy.

## Relationship to Recuriosity (Amnesiac Failure)

[[recuriosity-episodic-context-3d-exploration-2026]] identifies a failure mode where a curiosity-driven agent *forgets* previously visited states due to episodic memory constraints — it re-explores regions it has already covered because the intrinsic reward doesn't track absolute novelty, only relative surprise within the episode.

This suggests that pure curiosity signals need to be combined with episodic memory mechanisms (tracking revisit count, state recency) to avoid the amnesiac failure. The combination of:
1. Curiosity signal (intrinsic motivation for learning progress)
2. Episodic counting (track absolute visit frequency)
3. Maximum-occupancy coverage (evenness penalty)

...is more robust than curiosity alone.

## LLM-Specific Considerations

In LLM-based agents, curiosity-driven exploration operates on different spaces:

- **Prompt space**: Curiosity about whether alternative prompts would yield better responses
- **Tool space**: Curiosity about unexplored tool capabilities
- **Memory space**: Curiosity about whether retrieved context is complete vs. what parametric knowledge provides
- **Reasoning space**: Curiosity about alternative reasoning paths (similar to CoT exploration)

The ICM approach has been adapted for LLM tool use: train a predictor on whether tool calls succeed given the current context, reward exploration of tool-state combinations with high prediction error.

## Open Questions

1. **Noisy-TV problem**: How do you prevent the agent from exploiting stochastic noise in the environment rather than structured complexity? The learning-progress formulation partially addresses this but is computationally expensive.
2. **Curiosity collapse**: When the world model becomes accurate enough everywhere, intrinsic reward goes to zero — the agent stops exploring even though the external task may not be solved. How to maintain exploration pressure in mature regimes?
3. **Scaling**: Does curiosity-driven exploration scale to high-dimensional state spaces (images, language) or does the prediction error signal become too noisy?
