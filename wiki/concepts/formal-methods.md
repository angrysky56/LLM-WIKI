# Formal Methods

Formal methods use mathematical reasoning to specify, develop, and verify software and hardware systems. Key techniques include:

- **Model checking** — exhaustive state space exploration
- **Theorem proving** — interactive or automated proof construction
- **Abstract interpretation** — sound over-approximation of system behavior
- **Refinement types** — types encoding logical specifications
