# Hybrid Agents

Hybrid agents combine deliberative and reactive layers, using reactive responses for immediate stimuli while reserving deliberative planning for complex, high-stakes decisions.

## Key Characteristics

- **Two-tier architecture**: Reactive layer for fast responses, deliberative layer for complex planning
- **Adaptive mode switching**: Selects reactive or deliberative path based on task complexity
- **Efficiency + depth**: Gets the speed of reactive systems with the capability of deliberative systems
- **Layered hierarchy**: Deliberative layer often sits above a reactive base layer
