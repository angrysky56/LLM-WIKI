# Scaling Laws

Scaling laws describe the empirical relationship between neural network performance and scale. Key findings:

**Kaplan et al. (2020) — Chinchilla scaling laws:**
- Loss scales as power laws in model parameters, dataset size, and compute
- Underlying data is more important than model size alone
- Optimal model size depends on compute budget

**Emergent capabilities:**
- Abilities appear non-smoothly at certain scale thresholds
- Some capabilities emerge suddenly (few-shot learning, chain-of-thought)
- Phase transitions in capability landscapes
