# Shapley Values

## Definition

A **Shapley value** is a solution concept from cooperative game theory that distributes the total value generated by a coalition of players fairly, based on each player's marginal contribution to every possible coalition they could join. Introduced by Lloyd Shapley in 1953, it answers the question: *"Given that a group of players jointly produces some value, how should that value be divided among them in a way that is fair according to a set of reasonable axioms?"*

Concretely, for a cooperative game with player set *N* and value function *ν* : 2^N → ℝ (where *ν*(S) is the value generated by coalition *S* ⊆ *N*), the Shapley value for player *i* is:

```
φ_i(ν) = Σ_{S ⊆ N\\{i}} [|S|!(|N|-|S|-1)! / |N|!] · [ν(S ∪ {i}) - ν(S)]
```

The weighting factor |S|!(|N|-|S|-1)! / |N|! ensures that each possible ordering of players entering the coalition is equally likely. The term [ν(S ∪ {i}) - ν(S)] is player *i*'s marginal contribution to coalition *S*. Together, the Shapley value is the *average marginal contribution* of player *i* across all possible coalition formation sequences.

## The Four Axioms (Shapley, 1953)

Shapley proved his value is the *unique* function φ: (N, ν) → ℝ^n satisfying four axioms:

1. **Efficiency**: The total value is fully distributed: Σ_i φ_i(ν) = ν(N). No value is created or destroyed.
2. **Symmetry**: If two players are interchangeable — meaning ν(S ∪ {i}) = ν(S ∪ {j}) for all coalitions S containing neither — they receive equal Shapley values.
3. **Dummy Player**: If player *i* contributes nothing to any coalition — ν(S ∪ {i}) = ν(S) for all S — then φ_i(ν) = 0.
4. **Additivity**: For any two games ν and ω on the same player set, φ_i(ν + ω) = φ_i(ν) + φ_i(ω). The value is linear across combined games.

The uniqueness theorem is the result's power: any method that satisfies these four intuitive fairness axioms must compute exactly the Shapley value. There is no alternative if you accept the axioms.

## Relationship to Banzhaf Value

The **Banzhaf value** (or Banzhaf power index) is a closely related solution concept that drops the efficiency axiom and instead normalizes by counting coalitions. For player *i*:

```
β_i(ν) = (1/2^{n-1}) · Σ_{S ⊆ N\\{i}} [ν(S ∪ {i}) - ν(S)]
```

Unlike the Shapley value, the Banzhaf value does not require total value to sum to ν(N) — it measures *raw marginal influence* rather than *fair share of a fixed pie*. This makes the Banzhaf value more natural for voting power analysis (where total power need not sum to any fixed quantity) while the Shapley value is more natural for cost allocation and ML attribution (where the total prediction is known and must be conserved).

The ProxySHAP 2026 paper shows both Shapley and Banzhaf interactions can be estimated efficiently via tree-based proxy models with residual correction. See [[proxy-based-shapley-banzhaf-2026]] for details.

## Computational Complexity

Computing exact Shapley values requires evaluating the value function over all 2^n coalitions — exponential in the number of players. This is not accidental: the problem is **#P-complete** in general (Deng & Papadimitriou, 1994). For any practical application with more than ~25 players, exact computation is infeasible.

Tractable approximations exist when the value function has exploitable structure:

| Structure | Method | Complexity |
|-----------|--------|------------|
| Tree ensembles | TreeSHAP | Polynomial |
| Linear functions | LinearSHAP | Closed form |
| Any (via tree proxy) | ProxySHAP (2026) | Polynomial |
| Stochastic | Monte Carlo sampling | O(n² log n) |
| Model-internal | DeepSHAP | Backprop |

The ProxySHAP result is particularly significant because it shows that *any* value function can be approximated by a tree ensemble proxy, and Shapley values can then be computed exactly on that proxy in polynomial time — an indirect approach that bypasses the #P-complete barrier. See [[proxy-based-shapley-banzhaf-2026]].

## Applications Beyond ML

### Cost Allocation and Revenue Sharing

The earliest practical application: dividing joint costs or revenues among participants in a shared enterprise. For example, utilities allocating the cost of a regional power grid among municipalities based on their marginal contribution to the grid's construction cost.

### Voting Power Analysis

The **Shapley-Shubik power index** (1954) applies Shapley values to weighted voting games. Each voter has a weight, and a coalition is winning if its total weight exceeds a threshold. A voter's Shapley value in this game measures their *a priori* voting power — the probability that their vote is pivotal. This has been applied to UN Security Council voting, EU Council voting weights, and shareholder voting.

### Data Valuation

In data markets and collaborative ML, Shapley values can determine each data point's contribution to model performance. The "data Shapley" (Ghorbani & Zou, 2019) treats each training example as a player in a cooperative game where the value function is model accuracy. Examples with high Shapley value contributed more to the model's performance and should receive larger payments or be retained under privacy constraints.

## SHAP: The ML Instantiation

[[shap]] (SHapley Additive exPlanations) is the most widely used ML application of Shapley values. SHAP treats each input feature as a player in a cooperative game where the value function ν(S) is the expected model output conditioned on knowing only the features in S. The Shapley values of this game form the feature-level explanation for any individual prediction.

Key relationship: SHAP inherits the Shapley axioms (local accuracy = efficiency, consistency = monotonicity) but adds practical computational heuristics. The confidence in SHAP's explanations is bounded by the accuracy of these heuristics — ProxySHAP (2026) improves this by providing exact polynomial-time computation via tree proxies.

See [[shap]] for the full treatment of SHAP.

## Open Questions

- **Causal Shapley values**: Shapley values measure *predictive* contribution. Can they be modified to recover *causal* contribution under known causal structure? Shapley-flow (Heskes et al., 2020) is one attempt, but the axioms conflict with causality in non-trivial ways.
- **Shapley values in sequential games**: Classical Shapley assumes simultaneous cooperation. What is the correct value when players act sequentially? The Shapley-Shubik index implicitly handles sequential pivotal votes, but a general sequential version of the axioms is open.
- **No-free-lunch in value function choice**: The Shapley value depends on the choice of value function ν. For ML predictions, ν(S) requires marginalizing out features not in S — which distribution to use (training, uniform, conditional) changes the resulting values. Is there a principled criterion for ν selection?
- **Large-scale data Shapley**: Computing Shapley values for every data point in a training set (millions of points) is still computationally prohibitive. Truncated Monte Carlo variants exist but lack accuracy guarantees.
