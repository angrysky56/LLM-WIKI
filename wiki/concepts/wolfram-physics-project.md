# Wolfram Physics Project

Stephen Wolfram's project applying the framework of **A New Kind of Science (NKS)** to fundamental physics, modeling the universe as a computational system of rewriting rules and causal networks.

## Core Ideas

- **Multiway Rewrite Systems**: The universe as a graph of all possible rewriting paths
- **Causal Networks**: Directed graphs where nodes are updating events and edges represent causal dependencies
- **Computational Irreducibility**: Many processes cannot be predicted without explicit simulation
- **Emergent Spacetime**: Space itself emerges from the topology of the causal network
