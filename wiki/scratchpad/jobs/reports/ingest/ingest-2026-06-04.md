## Lessons / Carryover Notes
1. **Duplicate detection must be part of the ingest workflow.** The agent sheet's Step 2.1 says "CHECK for duplicates first" but my implementation only used `synapse_recall` (graph facts) — not `wiki_search` (page titles/summaries). A 06:21 page creation by a parallel cron run slipped through. **Fix for next time**: add `wiki_search(query="<paper title>")` to the duplicate-check step, not just `synapse_recall`.
2. **64KB+ files require split-then-ingest strategy.** Confirmed: 64KB times out, 398KB times out, but 42KB chunk succeeds. The carryover from yesterday flagged this; today I implemented the split. Document this as a primary pattern, not an edge case.
3. **Parallel cron runs can race on the same raw/ files.** Multiple sheets fire around 06:30 (ingest, arxiv, news, researcher). They all process the same raw/ files and can create duplicate wiki pages. Possible fixes: (a) a shared lock file in raw/, (b) post-ingest deduplication step, (c) agent sheet coordination. This is a process-level issue, not an ingest-skill issue per se.
