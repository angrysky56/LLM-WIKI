## Core Insight

Open-ended evolution (OEE) splits into two tiers: **weak OEE** (unbounded novelty within a fixed computational framework) and **strong OEE** (system creates its own new selective pressures, levels of organization, and substrates). AGEM demonstrates partial OEE through evolving conceptual complexity (27→64→104 nodes across 3 cycles), but remains within a fixed representational framework — true strong OEE requires architectural innovations that can outgrow their own description.

## Key Claims

| Claim | Detail |
|-------|--------|
| **Weak OEE** | Unbounded novelty within fixed computational framework (e.g., novelty search algorithms) |
| **Strong OEE** | System creates its own new selective pressures and computational substrates |
| **Four OEE Axioms** | Unbounded novelty, complexification, major transition capacity, autonomy (self-modifying search) |
| **Major Transitions** | Maynard Smith & Szathmáry: replicators→cells→multicellular→colonies→culture |
| **Autopoiesis** | Maturana & Varela: systems maintaining identity while enabling unbounded change |
| **Novelty Search** | Replaces fitness pressure with novelty pressure — prevents evolutionary stagnation |
| **The Paradox** | To achieve OEE, a system must be capable of outgrowing its own description (Gödel-like bootstrapping) |
| **AGEM Result** | 104 nodes, 7 communities, modularity 0.558, H¹=0 (no obstructions), entropy slope +0.69 |
