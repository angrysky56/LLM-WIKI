# Kanban (development)

## Core Concept

Kanban is a lean method for managing and improving work across human systems, originating from the Toyota Production System (1940s). It visualizes work items on a board and pulls work as capacity permits, rather than pushing work into the process on demand. Commonly used in knowledge work and software development, often combined with Scrum.

## Key Points

- **Visual workflow**: Kanban boards show work items from start to finish, making progress and process visible
- **WIP limits**: Work in Progress is capped at each stage to prevent bottlenecks and improve flow
- **Pull system**: Work is pulled as capacity permits, not pushed on request
- **Service Level Expectation (SLE)**: Forecast of how long a work item should take from started to finished
- **Six core practices**: Visualize workflow, manage flow, limit WIP, make policies explicit, implement feedback loops, improve collaboratively
