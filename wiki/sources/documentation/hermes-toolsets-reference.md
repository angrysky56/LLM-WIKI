# Toolsets Reference — Hermes Agent

**Source:** Official documentation for Hermes Agent's toolset configuration. Available at `hermes-agent.nousresearch.com/docs/reference/toolsets-reference`.

**Summary:** Toolsets are named bundles of tools that control what the agent can do. They are the primary mechanism for configuring tool availability per platform, per session, or per task.

**Key Concepts:**
- Every tool belongs to exactly one toolset
- Enabling a toolset makes all tools in that bundle available
- Configured per platform, session, or task scope
