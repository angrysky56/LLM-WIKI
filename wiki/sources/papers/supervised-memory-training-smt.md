# Supervised Memory Training (SMT) — Pretraining Recurrent Networks without Recurrence

**Authors:** Akarsh Kumar, Phillip Isola (MIT)  
**arXiv:** [2606.06479v1](https://arxiv.org/abs/2606.06479v1) | June 2026  
**Tags:** `cs.LG`, `cs.AI`

---

## Problem

Training recurrent neural networks (RNNs) requires assigning credit across long sequences of computations. Backpropagation through time (BPTT), the standard approach, has two fundamental weaknesses:

1. **Sequential in time** — the gradient must flow backward through every timestep, limiting parallelism to the forward pass only
2. **Vanishing/exploding gradients** — long-range dependencies become exponentially harder to learn as sequence length grows

These problems mean BPTT-trained RNNs cannot effectively scale to the long sequences where recurrent architectures would be most valuable — despite the theoretical appeal of RNNs (constant memory per step, biological plausibility, temporal abstraction).

## Method: Supervised Memory Training (SMT)

The core idea: instead of backpropagating errors through time, train the RNN on *supervised memory transition targets* generated by a separate teacher model.

### Two-Phase Training

**Phase 1 — Supervised Memory Training (SMT):**
- A Transformer-based encoder-decoder teacher processes the input sequence in parallel
- The teacher produces predictive hidden states (memory targets) for each timestep
- The student RNN is trained via supervised regression on these one-step memory transitions
- The gradient path between any two tokens is **O(1)** (constant) — not O(T) (linear) as in BPTT
- Training is fully time-parallel

**Phase 2 — Differentiable Memory Training (DMT):**
- After SMT pretraining, the RNN is finetuned with a differentiable signal through its own recurrence dynamics
- This allows the model to surpass the teacher's expressivity

### Key Architectural Choice

The paper restricts analysis to **nonlinear RNNs** — transformers and linear RNNs (Mamba, RWKV) are explicitly excluded as "qualitatively distinct model classes." The experimental setup uses RNNs with Transformer, MLP, and GRU backbone architectures.

## Results

**Synthetic Task Performance:**
SMT→DMT (SMT pretraining + DMT finetuning) outperforms BPTT on **all 5 synthetic tasks** across all difficulty settings:

| Task | What It Tests | SMT→DMT vs BPTT |
|------|--------------|-----------------|
| Retrieval | Gradient stability with long sequences | BPTT fails at long sequences; SMT agnostic |
| String Copy | Memory capacity | BPTT underutilizes memory; SMT scales |
| Stack Operations | State tracking complexity | SMT maintains accuracy with complexity |
| Keys-Values | Associative recall | SMT handles more associations |
| Modular Arithmetic | In-context learning | SMT learns from more examples |

BPTT struggles across the board as sequences grow longer, even on the simplest task (retrieval). SMT is "agnostic to sequence length" — its performance does not degrade as sequences extend.

**Naturalistic Tasks:**
- Character-level language modeling on TinyStories
- Pixel sequence modeling on MNIST and Sketchy (raster-scan order — "Attneave's task," a notoriously hard long-range credit assignment problem for RNNs)

## Limitations

1. **Teacher bottleneck** — The Transformer teacher is time-parallel and thus constrained in expressivity. SMT-trained RNNs may inherit these constraints and may need BPTT finetuning to surpass the teacher
2. **Two-phase training** — Requires training a teacher model first, doubling the training pipeline complexity
3. **Nonlinear RNNs only** — Does not address the broader class of sequence models (linear RNNs, transformers)
4. **Scalability to LLM-scale** — Results are on small benchmarks; whether SMT works at GPT-scale is unproven

## Key Quote

> "SMT enables nonlinear RNNs to better capture long-range dependencies and train in parallel, potentially unlocking the scaling of models that build temporal abstractions of past information."

## Connections

- Directly challenges the dominance of BPTT for RNN training, a paradigm largely unchallenged since the 1990s
- Related to **forward-mode differentiation** and **real-time recurrent learning** (RTRL) literature, but SMT avoids the O(n⁴) cost of RTRL by using supervised targets
- Contrasts with **linear RNNs** (Mamba, RWKV, LRU) which solve the gradient problem through architectural constraints rather than training algorithm innovation
- Relevant to the **credit assignment** thread in the wiki — SMT represents a fundamentally different approach from both BPTT and forward-mode methods
- Potential implications for **online learning** scenarios where BPTT is impractical (cannot store the full computation graph)
