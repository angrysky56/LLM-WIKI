# CodeGraph

[[codegraph]] is a **local code knowledge graph** that supercharges AI coding tools (Claude Code, Codex, Cursor, OpenCode, Hermes Agent) with semantic code intelligence.

## Key Claims

- ~35% cost reduction
- ~70% fewer tool calls
- 100% local processing

## Installation

```bash
# macOS / Linux
curl -fsSL https://raw.githubusercontent.com/colbymchenry/codegraph/main/install.sh | sh

# Windows (PowerShell)
irm https://raw.githubusercontent.com/colbymchenry/codegraph/main/install.ps1 | iex
```

No Node.js required — one command grabs the right build for your OS. npm install also available for any Node version.

## Architecture

Pre-indexed code knowledge graph — builds an index of code structure and semantics for fast retrieval during coding assistance sessions.
