## Core Insight

GSD is a spec-driven development methodology using meta-prompting and context engineering to decompose work into disciplined phases: discuss → plan → execute → verify → ship. It emphasizes explicit phase completion before advancing and uses structured manifests for state tracking.

## Key Claims

| Phase | Purpose |
|-------|---------|
| **Discuss** | Gather context, clarify requirements |
| **Plan** | Create SPEC.md with clear acceptance criteria |
| **Execute** | Build to spec |
| **Verify** | Check against acceptance criteria |
| **Ship** | Deliver and validate |

GSD manifests track phase state and prevent skipping steps.
