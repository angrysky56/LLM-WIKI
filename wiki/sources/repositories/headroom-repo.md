# chopratejas/headroom — GitHub Repository

**Source:** [github.com/chopratejas/headroom](https://github.com/chopratejas/headroom)

**Summary:** A context optimization layer for LLM applications that compresses tool outputs, logs, files, and RAG chunks before they reach the model. Achieves 60–95% fewer tokens with the same answers. Licensed under Apache 2.0, local-first.

**Packages:**
- Python: `headroom-ai`
- TypeScript: npm package
- Proxy: OpenAI + Anthropic-compatible HTTP proxy
- MCP: `headroom_compress`, `headroom_retrieve`, `headroom_stats` tools
