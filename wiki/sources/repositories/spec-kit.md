# spec-kit: Spec-Driven Development Toolkit

An open source toolkit by GitHub for Spec-Driven Development — a methodology where specifications become executable and directly generate working implementations rather than just guiding them. Uses the `specify` CLI, which integrates with GitHub Copilot.

## Key Features

- **Spec-Driven Development**: Flips the traditional code-first script — specs are executable, not throwaway scaffolding
- **Specify CLI**: Installable via `uv tool install specify-cli` from the spec-kit GitHub repo
- **Init Projects**: `specify init my-project --integration copilot` to bootstrap a spec-driven project
- **Copilot Integration**: Designed to work with GitHub Copilot for spec-to-code generation
- **Open Source**: Hosted at github/github/spec-kit
